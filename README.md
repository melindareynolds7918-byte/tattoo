# Southside Ink

A one-page appointment booking experience for Southside Ink, built with Vite, React, and CSS.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite. The booking form is a front-end demo: submit an inquiry to see the confirmation state.

## Email delivery

The booking form uses the React integration from `@formspree/react` and submits to Formspree form `xeaokvrj`. Formspree routes the entries to the inbox configured in your Formspree dashboard. No local email credentials are stored in the site.
